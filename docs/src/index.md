# NLPModelsExtensions.jl

Extension package for [NLPModels.jl](https://github.com/JuliaSmoothOptimizers/NLPModels.jl).

`using NLPModelsExtensions` brings every submodule's exports into scope.
`using NLPModelsExtensions.ParametricNLPModels` brings only that submodule's exports.

| Submodule | Description |
|---|---|
| [ParametricNLPModels](ParametricNLPModels/index.md) | Parametric sensitivity interface |

NLPModelsExtensions.NLPModelsExtensions — Module
NLPModelsExtensions

Extensions of the NLPModels API as one chain of abstract types:

AbstractNLPModel
└── AbstractBatchedNLPModel      a batch of NLPs sharing one sparsity pattern
    └── AbstractParametricNLPModel   + derivatives with respect to parameters
          = AbstractExtNLPModel      the type to subtype

A single problem is a batch of size 1 and a problem without parameters has npar = 0, so every model subtypes AbstractExtNLPModel. Code that consumes models accepts the least derived type it needs. An ordinary AbstractNLPModel is wrapped with ExtNLPModel.

source
NLPModelsExtensions.AbstractBatchedNLPModel — Type
AbstractBatchedNLPModel{T, M <: AbstractMatrix{T}} <: AbstractNLPModel{T, M}

A batch of nbatch NLPs that share dimensions and the sparsity patterns of the Jacobian and the Hessian of the Lagrangian; only the numerical data and the bounds differ. Data are matrices of type M with one column per instance, and get_nvar, get_ncon, get_nnzj and get_nnzh are per instance. A single problem is a batch with nbatch = 1.

Concrete models store a BatchedNLPModelMeta in nlp.meta and a Counters in nlp.counters, as in NLPModels.

source
NLPModelsExtensions.AbstractExtNLPModel — Type
AbstractExtNLPModel{T, M <: AbstractMatrix{T}}

The model type to subtype: batched (nbatch = 1 for a single problem) and parametric (npar = 0 without parameters). Other packages extend it with their own subtypes, giving any new function a neutral default so their models remain usable wherever an AbstractExtNLPModel is accepted.

AbstractExtNLPModel is an alias of the bottom of the chain, currently AbstractParametricNLPModel, which is the name Julia prints.

source
NLPModelsExtensions.AbstractParametricNLPModel — Type
AbstractParametricNLPModel{T, M <: AbstractMatrix{T}} <: AbstractBatchedNLPModel{T, M}

A batched NLP with derivatives with respect to parameters, a npar × nbatch matrix with one column per instance. Dimensions come from get_par_meta, which defaults to no parameters.

source
NLPModelsExtensions.BatchedNLPModelMeta — Type
BatchedNLPModelMeta(nvar, nbatch; kwargs...)

Metadata of a batch of nbatch NLPs with nvar variables each. Data are matrices with one column per instance.

  • x0, lvar, uvar: initial point and variable bounds, nvar × nbatch
  • ncon: number of constraints per instance
  • y0, lcon, ucon: initial multipliers and constraint bounds, ncon × nbatch
  • nnzj, nnzh: nonzeros per instance in the Jacobian and in the lower triangle of the Hessian of the Lagrangian
  • minimize: whether the instances are minimized
  • name: name of the batch

get_nvar, get_x0 and the other NLPModels getters work on the meta and on the model.

source
NLPModelsExtensions.ExtNLPModel — Type
ExtNLPModel(model)

Wrap an ordinary AbstractNLPModel as an AbstractExtNLPModel: a batch of one instance, with data as one-column matrices. Evaluations are forwarded to model on the first column, and the counters are those of model.

Defaults to no parameters (npar = 0). The package that defines the type of model adds parameters by extending get_par_meta and the parametric functions on ExtNLPModel{T, M, <:ModelType}, e.g. ExaModels for an ExaModel.

source
NLPModelsExtensions.ParametricNLPModelMeta — Type
ParametricNLPModelMeta(; kwargs...)

Metadata for the derivatives with respect to the parameters. Counts are per instance: the sparsity patterns are shared by the batch.

  • npar: number of parameters per instance
  • nnzo_par: number of nonzeros in $∂f/∂θ$
  • nnzj_par: number of nonzeros in $∂c/∂θ$
  • nnzh_par: number of nonzeros in $∂²L/∂x∂θ$
  • nnzj_lvar_par, nnzj_uvar_par, nnzj_lcon_par, nnzj_ucon_par: number of nonzeros in $∂x^ℓ/∂θ$, $∂x^u/∂θ$, $∂c^ℓ/∂θ$, $∂c^u/∂θ$
  • grad_par_available, jac_par_available, hess_par_available, jprod_par_available, jtprod_par_available, hprod_par_available, htprod_par_available: whether the function is implemented

NLPModelsExtensions.hess_par_coord! — Method
V = hess_par_coord!(nlp, X, Y, σ, V)

Evaluate the Lagrangian Hessian with respect to the variables and the parameters $∂²L/∂x∂θ(x,y)$ at the columns of (X, Y) in sparse coordinate format, with the objective of instance k scaled by σ[k], i.e.,

\[∂²L/∂x∂θ(x,y) = σ ∂²f/∂x∂θ(x) + \sum_i yᵢ ∂²cᵢ/∂x∂θ(x),\]

with σ the objective weight of the instance, overwriting V (nnzh_par × nbatch). Defaults to doing nothing when nnzh_par = 0.
